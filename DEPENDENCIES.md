# Runtime dependencies

- [WordPress Abilities API in WordPress 6.9 or later](https://developer.wordpress.org/apis/abilities-api/) provides the native registration and execution interfaces used by all 79 core abilities.
- [PHP 8.0 or later](https://www.php.net/releases/8.0/en.php) runs the plugin code.
- [WordPress MCP Adapter](https://github.com/WordPress/mcp-adapter/) exposes registered WordPress abilities to MCP clients.
